隐私与数据说明

本说明解释 POIresearch 收集哪些公开数据、为何收集、如何保存，以及数据主体如何提出删除请求。

生效日期 2026-11-02版本 1.0仅限公开信息
本页目录 适用范围 收集内容 使用目的 保存与安全 共享与公开 数据主体权利 Cookie 与日志

1. 适用范围

本网站是 POIresearch 的项目说明页，不提供微博账号注册、公开搜索或数据下载服务。本说明适用于本项目通过微博开放平台经授权接口获取和处理公开微博数据的过程。

2. 收集哪些数据

项目仅处理完成城市空间统计所必要的公开信息：

  • 公开微博编号、发布时间与公开正文；
  • 公开地点名称、POI 编号及帖子主动公开的签到坐标；
  • 微博平台已公开显示的省级 IP 属地；
  • 公开的点赞、评论和转发数量，用于描述传播程度。
不收集：真实 IP 地址、设备标识、通讯录、私信、支付信息、精确 GPS、身份证信息或其他非公开个人资料。

3. 使用目的

  • 分析杨浦区不同时间段的公开微博活动变化；
  • 比较公园、街区、校园和商业空间的活动分布；
  • 开展课程作业、论文研究和结果复核；
  • 制作仅包含汇总统计的图表和研究报告。

数据不会用于广告投放、商业营销、用户画像、信用评价、人员追踪或任何违法用途。

4. 保存、期限与安全

原始明细仅保存在项目研究者控制的本地设备或受访问控制的研究存储中。访问凭证不写入网页、版本库或公开日志。

  • 采集遵循最小必要原则，不保存与研究问题无关的字段；
  • 原始明细在研究周期结束后删除；
  • 研究发表时只保留不可逆的聚合统计；
  • 如发现数据泄露，将立即停止处理、限制访问并核查影响。

5. 共享与公开

项目不出售、出租或交换数据，不向广告商、数据经纪商或其他无关第三方提供原始微博明细。除法律法规要求或数据主体明确授权外，不进行对外共享。

论文或展示中不会公开可重新识别个人的主页链接、原微博全文或连续位置轨迹。必要引用会遵守平台规则和学术规范。

6. 数据主体的权利

数据主体可通过微博开放平台应用资料中登记的联系方式提出查询、更正、限制处理或删除请求。项目研究者将在合理期限内核验请求并处理相关原始记录。

如果内容已在微博平台删除或设为私密，项目不会尝试恢复该内容。

7. Cookie、统计与第三方服务

本网站不使用广告 Cookie、第三方分析脚本、追踪像素或外部字体，访问本网站不需要提交个人信息。网站由 GitHub Pages 静态托管，因此托管服务会接收页面访问请求；授权码可能短暂出现在页面地址中，项目研究者会立即在受控设备上完成交换，不把授权码交给广告、分析或其他无关第三方。

说明更新

当研究范围、数据字段或处理方式发生实质变化时，本说明将更新版本号和生效日期。最新版本始终发布在本页面。
