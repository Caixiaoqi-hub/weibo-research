应用说明

本页说明 POIresearch 的研究范围、申请微博开放平台接口的目的、数据处理流程和明确排除的行为。

1. 项目目标

POIresearch 是一个独立的个人学术研究项目，研究上海市杨浦区城市空间的微博活动分布。项目关注公园、街区、校园、商业空间等公共地点在不同时间尺度上的活动差异。

项目不提供商业营销服务，不构建个人画像，不追踪单个用户的行动轨迹。研究成果以空间单元和时间段的汇总统计呈现。

项目性质：非商业、非公众服务、非微博官方产品。仅由项目研究者使用已登记的开放平台应用完成授权和数据获取。

2. 申请接口的用途

项目拟使用地点时间线能力，按公开坐标、查询半径和时间范围获取公开微博。相比之下，关键词搜索无法发现正文没有提到地名、但主动选择公开地点的帖子。

申请能力

  • 微博开放平台应用来源审核；
  • 地点时间线相关接口权限；
  • 使用范围仅限本项目申请中说明的杨浦区城市研究。

不申请的权限

  • 不申请私信、通讯录、支付或其他账号敏感权限；
  • 不采集用户真实 IP、设备标识或精确 GPS；
  • 不提供批量账号注册、代登录或第三方用户登录服务。

3. 处理的数据字段

仅保留完成空间统计所需的公开字段。若接口不返回某字段，项目不会通过其他方式绕过平台限制进行推断。

字段用途处理原则
微博编号去重与结果复核仅用于研究数据管理
发布时间月度与时段聚合不用于追踪个人
公开正文主题分类与内容分析结果只展示汇总
公开 POI 与坐标区域校验和空间统计不推断设备位置
平台公开 IP 属地辅助核验内容来源只保留公开省级信息
互动数量描述内容公开传播程度不作为个人评价依据

4. 采集与处理流程

  1. 研究者在开放平台完成本人账号授权，授权凭证仅存放在受控设备。
  2. 按申请中说明的坐标范围和时间窗口调用公开地点接口。
  3. 对返回的微博编号去重，剔除与研究区域无关的误入数据。
  4. 仅对公开正文和公开地点进行分类、统计和可视化。
  5. 研究周期结束后删除原始明细，仅保留不可逆聚合结果。

访问控制

网站本身不提供账号登录、数据查询或下载功能，不向公众转发微博内容。OAuth 回调页由 GitHub Pages 静态托管，只负责展示授权结果；研究者随后在受控设备上完成授权码交换，不将授权码发送给广告或分析服务。

5. 范围与限制

  • 研究范围限定为上海市杨浦区，不追求全国性覆盖。
  • 只分析平台公开展示且接口返回的内容。
  • 无法恢复已删除、设为私密或平台未提供的历史微博。
  • 不对普通微博推断签到地点，不伪造位置字段。
  • 不绕过平台频率限制、访问控制或账号安全机制。

6. 联系与审核信息

应用名称：POIresearch。审核相关补充信息、研究说明和数据删除申请，请通过微博开放平台应用资料中登记的联系方式与项目研究者联系。
